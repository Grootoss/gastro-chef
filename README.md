# GastroChef

Лендинг сервиса здорового питания GastroChef: detox-программа, преимущества,
рационы, фото блюд, заказ и ответы на вопросы.

Сайт собран как одностраничное приложение. Базовый путь сборки — `/gastro-chef/`,
его забирает GitHub Pages.

## Стек

- React 19 и TypeScript
- Vite 8
- React Router 7
- CSS Modules
- ESLint, Stylelint и Prettier

## Брейкпоинты

Вёрстка mobile-first. Базовые стили — мобильный экран, дальше включаются
медиазапросы.

| Экран     | Условие             | Ширина макета                     |
| --------- | ------------------- | --------------------------------- |
| Мобильный | без медиазапроса    | 480px                             |
| Планшет   | `min-width: 768px`  | 768px                             |
| Десктоп   | `min-width: 1920px` | на всю ширину, боковые поля 315px |

У промо на десктопе секция ограничена 1920px. Шапка на этом экране собрана в
колонку шириной 1600px. Блок фото между 768px и 1919px живёт отдельно: там свой
планшетный ряд, а с 1920px карточки снова идут лентой.

## Стили

Общие стили лежат в `src/styles`.

- `fonts.css` — Roboto через `@font-face`
- `variables.css` — палитра, на каждый цвет своя переменная
- `global.css` — основной шрифт, `font-size: 16px` и `line-height: 1.5`

Стили секций — CSS-модули рядом с компонентами. Отступы, у которых одна из
сторон равна нулю, записаны отдельными свойствами: `padding-top`,
`margin-left` и так далее.

## Шрифт

Файлы лежат в `public/fonts`.

| Начертание | `font-weight` | Файл                   | Где используется                                               |
| ---------- | ------------- | ---------------------- | -------------------------------------------------------------- |
| Regular    | 400           | `Roboto-Regular.woff2` | основной текст                                                 |
| Medium     | 500           | `Roboto-Medium.woff2`  | меню, вопросы FAQ, подписи программ и заказа, ссылки в подвале |
| Bold       | 700           | `Roboto-Bold.woff2`    | заголовки и кнопки                                             |

У шеврона в FAQ стоит `font-weight: 300`. Отдельного файла Light в папке нет,
поэтому этот знак рисуется из Regular.

## Скрипты

```bash
npm install
npm run dev
npm run build
npm run preview
npm run lint
npm run lint:styles
npm run format
```

`npm run dev` поднимает Vite. `npm run build` проверяет TypeScript и собирает
статику в `dist`. Публикация на GitHub Pages идёт через
`.github/workflows/deploy.yml` при пуше в `main`.

## Редактор

В корне лежит `.editorconfig` из проекта Pizza Shop: UTF-8, отступ в 2 пробела,
перевод строки LF, конечная пустая строка. Prettier и Stylelint подхватывают
тот же стиль: `npm run format` прогоняет Prettier по проекту.
